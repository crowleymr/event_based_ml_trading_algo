# Dashboard feedback
I need you to prepare a plan that diagnoses problems with the report and then outlines a plan to improve the visual quality of the report 

## Overall
* More care is needed in the data story being told. Each tab should be telling a story that fits in with the grander narrative of the project analysis objective.
* Greater use of charts are needed, with each tab presenting a considered best practice choice of what charts and tables to include
* test/validation split CAN be a filter, however in many cases it needs to be shown as a side-by-side metric in many situations
* A dropdown of each "run" would be more useful Evidence filter
* In data storytelling I prefer to "show don't tell", and try to demonstrate comparisons graphically whenever possible. 
* **Charts must be front and centre** to give quick understanding to the audience on a key point being made. 
* Whereas tables are needed, but only presented with some "digging", "clicking" or "scrolling" and no more rows than the number of models. 
* **Directive:** A table that is essentially a dataset imported into a dashboard has no place in being presented as it is not a summary.
