# Assignment support workspace

These are living materials for later student refinement, not a submitted paper or final PDF. Generated results must come from the reporting command and immutable run artefacts under the repository evidence policy.

| Document | Use |
|---|---|
| [TASK_AND_IO.md](TASK_AND_IO.md) | Precise problem, motivation and train/inference contracts |
| [MODELS_AND_COMPONENTS.md](MODELS_AND_COMPONENTS.md) | Algorithms, objectives, fitting and code map |
| [EVALUATION_AND_DISCUSSION.md](EVALUATION_AND_DISCUSSION.md) | Metrics, methodology, limitations, behavior, implications and future work |
| [PAPER_AND_PRESENTATION_OUTLINE.md](PAPER_AND_PRESENTATION_OUTLINE.md) | Evidence-led paper and five-minute presentation structure |
| [STUDENT_REFLECTION_PROMPTS.md](STUDENT_REFLECTION_PROMPTS.md) | Clearly marked prompts requiring the student's own first-person evidence |
| [AI use register](../AI_USE_AND_VERIFICATION.md) | Factual challenges, AI actions and independent verification |

Do not turn prompts into invented first-person claims. The student should edit them after reviewing the code, generated tables and verification record.
