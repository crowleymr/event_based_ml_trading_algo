## Generated documentation

Run-local `summary.md`, plots and metrics are immutable execution artefacts. Versioned coded reports are derived from one specified `runs/<run_id>/` contract and live outside that contract. Generated values supersede any prose transcription.

## Future documentation

Future research protocols, data-source policies, model cards and operational runbooks should be added only when their stage gate in [BACKLOG.md](BACKLOG.md) is approved. Do not describe planned RL, alternative assets, richer data, UI or paper trading as present capability.
